# Validation scope / 验证范围

2026-10-31. This public preview separates device reports, hardware simulation, compilation and new distribution-tool testing.

| Level | Evidence | Limit |
|---|---|---|
| Pocket user report | Chinese pages and GB/GBC game launch confirmed; 0.1.2 folder-transition flash fix accepted on Analogue OS 2.5 | One device/user; not a full game, sound, save or suspend compatibility matrix |
| Native RTL regression | Old-code negative controls reproduce video drop; repaired boot/A/B/Home paths keep 320×288 menu timing over 105 frames and 6 loads, with black loading pixels | APF/SDRAM models; game CPU and save payload are stubs |
| Native launch regression | Launch/pause/save-return/resume flow and video handoff pass in the model | Does not certify real save contents or real game execution |
| FPGA compile | Full Quartus build and constrained timing pass; resources/hashes in [BUILD](BUILD.md) | Upstream unconstrained I/O remains |
| Public library/installer | Automated synthetic-fixture tests cover native text columns, parent links, source preservation, isolated saves, checksums, interrupted install and rollback | New generic package tool output has not been independently accepted across multiple devices |
| CI | Python tests and repository/source checks on Linux and Windows | No Quartus build or hardware test in CI |

The public RTL is equivalent to the accepted lab source after line-ending normalization; the distributed `.rbf_r` is byte-identical. A fresh clone is checked independently before public release.

The preview image is generated by the actual RTL using original placeholder graphics and synthetic entries. It demonstrates the displayed menu, not game compatibility.

Known issues: occasional flash at game launch, perceived loading delay, incomplete coverage of sound/controls/ordinary saves/suspend behavior, no automatic title translation, no GBA/NES/SNES integration or runtime cross-core launcher. New distribution tools do not automatically migrate existing progress.

This repository deliberately excludes private device identifiers, card inventories and game/save data. Public release receipts record software hashes and test scope rather than a private user's library.
