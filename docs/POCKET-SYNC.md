# Pocket Sync 的适用范围

已核对 [Pocket Sync v7.2.0 官方说明](https://github.com/neil-morrison44/pocket-sync/blob/v7.2.0/README.md)：支持桌面中文、核心管理和存档备份／恢复；首次连接会写 `pocket_sync.json`。这不是纯只读连接，也不能替换 Pocket 本机系统菜单。

本项目旧 GBA `.3` 使用 F1 菜单，新 `.6` 需要配套 F2 资源。单独拖入 core ZIP 不会完成格式转换或本项目的版本／进度核对；已有中文入口使用[整批工具](BATCH-UPDATE.md)的备份更新流程。Pocket Sync 可用于桌面查看和另外的备份管理，先连接电脑副本。其固件更新功能不属于本任务。

安装包已下载并核对官方发布信息和 SHA256；未据此宣称完成 GUI 启动或真实卡连接验证。

## English

[Pocket Sync v7.2.0](https://github.com/neil-morrison44/pocket-sync/blob/v7.2.0/README.md) documents Chinese desktop UI and save backup/restore. First connection writes a configuration file. It does not replace Pocket OS. Our GBA F1-to-F2 migration still needs the matching library and backed-up batch workflow; a core-only ZIP is insufficient. Installer availability/hash are verified separately from unperformed GUI/device checks.
